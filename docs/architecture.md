# Orchestra Architecture (v2)

Supervisor daemon (sole SQLite writer) + Pi RPC agents + shotd. See RECON.md for Pi map, DEVIATIONS.md for changes.

## A. What was proven (2026-11-07)

- Real `pi --mode rpc -e agent-ext --model faux-rpc/faux-1`: `get_state` (model faux-1, thinking off), `prompt` → `agent_start` → `tool_execution write` → `agent_end` → `agent_settled`, `steer` → `disposition queued`. Extension flags work. Script: `/tmp` RPC test (see report).
- shotd live Chrome (CDP): cold 2187ms, warm 1263ms, sameHash true, 3840×2160, WebP valid. Bench: cold 3484ms, warm 1189ms, 6 contexts one browser 7442ms. Tools: shot/zoom/dom_metrics/baseline_save/baseline_diff/close_context all implemented; diff catches small changes (see tools.test.ts). `screenshot_diff`/`dom_assert` wired via lazy shotd import + `runChecksAsync`.
- Security: 127.0.0.1 only + per-agent Bearer token (migration v2 `agents.token`). Tests: missing/wrong/cross-agent → 401, correct → 200 (product.test.ts). DEVIATIONS D11.
- Planner prompts: versioned DB rows, goal verbatim, checks literal, teammates, workflow, evidence required (planner.ts). Watchdog: deterministic evidence audit + LLM review hook + targeted reprompt (no generic). Comms: 5 detectors (comms.ts). Thinking: fixed/dynamic rubric, live `set_thinking_level` (levels off/minimal/low/medium/high/xhigh/max/ultra). Report: `orchestra report` + `orchestra watch` (read-only).
- /supervisor TUI extension: `registerFlag("supervisor")` + `registerCommand("supervisor")` in packages/orchestra-supervisor-ui, lazy dynamic import, settings at ~/.pi/agent/settings.json (orchestraSupervisor key), `/supervisor off` returns to plain Pi, idempotent. Envelope pick in UI layer; planner picks exact inside envelope. Off-by-default: no server on import (off-default.test.ts).
- Layout: perTab from cells (minCols 80/minRows 22, maxPerTab 8): 200×55→4, 250×70→8, tiny→2. iTerm2 AppleScript via native splits (no keystrokes), tmux fallback. Unit-tested; real window smoke not run (dry-run script only).

## C. Desktop control (Part C)

External pinned agent-desktop (vercel-labs, Apache-2.0; never vendored, no Rust in this repo). Researched at `/private/var/folders/ct/cwpf7vpn059fkp932tq9zm4m0000gn/T/opencode/agent-desktop-upstream` (outside the repo; nothing committed).

- **CLI (`orchestra doctor`)**: `packages/orchestra-cli/src/index.ts` (doctor logic, testable) + `cli.ts` (thin dispatch). Checks binary (PATH or `AGENT_DESKTOP_BIN`), runs `version` (JSON) then `status`, compares the exact version string against pinned **1.0.2**, prints the result, and prints macOS guidance (System Settings > Privacy & Security > Accessibility / Screen Recording, plus Automation) without ever granting permissions or opening System Settings. Exits non-zero on missing binary, version mismatch, failed status, missing permissions, or failed/poor bench. `doctor --bench [--app <name>]` (default `TextEdit`) snapshots `-i`, measures latency, counts refs with accessible names vs `ref_count`, and prints `POOR TREE` in plain words when `complete=false`, refs are empty, or any ref lacks a name — no papering over. Existing commands (`up|status|report|watch`) unchanged.
- **Extension (`desktop` tool)**: `packages/orchestra-agent-ext/src/desktop.ts` (new) + `index.ts` (registers one tool + `tool_call` guard). Verbs only: `snapshot`, `act`, `verify` (re-snapshot), `screenshot`. Capability-gated OFF by default: `ORCHESTRA_DESKTOP_CAPABILITIES` must include `desktop` and `ORCHESTRA_DESKTOP_ALLOWED_APPS` must list the app; `AGENT_DESKTOP_BIN` overrides the binary. Missing capability/allowlist fails the tool with an error (never silent); the guard blocks `desktop` calls and `bash` commands containing `agent-desktop` when the capability is not declared. Retry honors `error.disposition.retry`: retried at most once and only for read-only commands when `safe`; ref actions never auto-retry (stale refs need a fresh snapshot).
- **Privacy**: tool results and event metadata store command/app/ok/error/ref-count only (plus sha256 hashes). Snapshot trees and screenshots go to `ORCHESTRA_DESKTOP_ARTIFACTS_DIR` (default `.orchestra/desktop-artifacts`, 0700/0600) and are TTL-cleaned (`ORCHESTRA_DESKTOP_ARTIFACT_TTL_MS`, default 24h). Payloads never enter messages or logs. Desktop screenshots reuse shotd's per-model `resizeForModel` via dynamic import (`@earendil-works/pi-shotd/image`); no resize math is duplicated. shotd stays the web-pages tool.
- **Leases**: `desktop` acquires file lease resource `app:<name>` per call (non-blocking, 30s TTL, O_EXCL create, expiry reclaim — same semantics as `Store` file leases). The supervisor has no `/app-lease` or `/event` endpoint and this part may not edit `orchestra-core`/`orchestra-supervisor`, so leases are a cross-process file contract and desktop event rows are deferred; the tool returns metadata that a future endpoint can persist verbatim (DEVIATIONS D19–D20).
- **Tests**: fake `agent-desktop` shims emitting real envelope shapes cover guard, leases, retry rules, and redaction in `orchestra-agent-ext/test/desktop.test.ts` + `orchestra-cli/test/doctor.test.ts`. Real smoke against TextEdit/Finder is gated behind `ORCHESTRA_DESKTOP_REAL_SMOKE=1` and was **not** run here (macOS permission not granted on this machine).
